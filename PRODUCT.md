## Users

The primary audience, confirmed by the user, is **self-directed beginners learning to code in a browser**. Their main job is to understand a concept, try real code, receive useful feedback, make visible progress and return to continue learning.

Projects and community support that learning journey: learners practice concepts, save their own work, build projects and share permitted work with others. Educator/student, reviewer/moderator and operator capabilities are later roadmap audiences; their detailed workflows and launch priority remain open.

## Product Purpose

CodeSaga is a planned browser-based, gamified coding platform with courses, real code execution, checked practice, durable progress, projects and community. The user confirmed this product brief.

The core success condition is a complete learning loop: discover appropriate content, read a lesson, edit/run code, understand execution or checking feedback, earn valid completion, and resume with source and progress intact. Completing that loop should not require learners to set up a local programming environment.

The full proposed feature scope, milestone ordering and observable acceptance outcomes live in [docs/ROADMAP.md](docs/ROADMAP.md). No application feature is implemented or verified merely because it appears in that plan.

## Product Principles

1. **Make learning actionable:** explanation, experimentation and understandable feedback form one coherent beginner journey.
2. **Earn trust through real outcomes:** executed code, checked answers and durable completion must reflect actual state.
3. **Preserve learner work:** source, saved revisions and progress remain recoverable and their persistence status is clear.
4. **Use progression to support learning:** rewards, projects and community reinforce practice without obscuring the next useful action.
5. **Keep product truth traceable:** reference evidence, confirmed user decisions, proposed design and implemented behavior have explicit authority and limits.
