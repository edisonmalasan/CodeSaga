# Public interface assets

- `public/media/camp-observatory.png`: original CodeSaga artwork generated for this project. Original PNG is preserved byte-for-byte with RGBA alpha and embedded `impeccable:prompt` provenance. The exact generation prompt sidecar is retained outside the public tree at `.impeccable/assets/camp-observatory.prompt.txt`. No captured reference-product assets are shipped.
- Silkscreen regular, from pinned `@fontsource/silkscreen` 5.3.0, is served locally by the build for the wordmark and display headings. Copyright and SIL Open Font License are preserved in `public/media/Silkscreen-OFL.txt`. Paragraphs use the device's system sans and code uses its monospace stack.
- Small interface SVGs in `src/components/icons.tsx` are authored geometric icons; no vector scene is used.
